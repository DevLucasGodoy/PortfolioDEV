## Overview

**FC Academy** is a course platform for creators and schools where each client gets its own site. It is in development.

## Solution

- **Host-based multi-tenancy**, including custom domains
- **Data isolation** with PostgreSQL Row Level Security
- **Centralized permissions** and plan limits
- **School pages**
- **Bilingual site** PT/EN

## Tech Stack

- Next.js 16, React 19, Drizzle ORM, PostgreSQL, Better Auth, Vitest
