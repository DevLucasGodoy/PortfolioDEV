## Overview

**Servix** is a system for small service providers such as repair shops, beauty and maintenance. It is in development.

_"Less paper. More service."_

## Solution

- **Service orders**
- **Weekly calendar**
- **Client records**
- **Finance** and service catalog
- **Public showcase** for each provider

## Tech Stack

- Next.js 15, React 19, Tailwind CSS 4
- PostgreSQL, Drizzle ORM, Auth.js, Zod
