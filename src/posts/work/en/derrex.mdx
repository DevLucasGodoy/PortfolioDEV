## Overview

**Derrex** is a complete digital operation for a supplement brand: sales site, management panel and native app. The site and panel are in production; the app is in store review.

## Solution

- **Access control** with 5 roles
- **Stock and cycles** tracked through a ledger
- **Digital contract signing** on first access
- **Image pipeline** to WebP on Cloudflare R2
- **Usage tracking** and push notifications in the app

## Tech Stack

- **Web**: Next.js 15, React 19, Auth.js, Prisma 7, PostgreSQL
- **Mobile**: Expo 57, React Native 0.86, expo-router, EAS
- **Infra**: Cloudflare R2, sharp

## By the numbers

42 Prisma models, 38 API routes, 34 panel pages and 26 mobile screens.
