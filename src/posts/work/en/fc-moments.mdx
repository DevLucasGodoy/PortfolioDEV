## Overview

**FC Moments** is a collaborative event gallery: every guest becomes a photographer and nothing gets lost. It is in beta.

_"Memories that last forever."_

## Solution

- **Vertical feed** of photos and videos
- **Direct upload** to Cloudflare R2 with file validation
- **Invites** via QR code or link
- **Likes and comments**
- **Password and expiry** on the public page
- **Dashboard** with multiple events

## Tech Stack

- Next.js 16, React 19, Neon with Row Level Security, Cloudflare R2, Resend, Tailwind CSS 4, Zod
