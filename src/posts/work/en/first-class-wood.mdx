## Overview

**First Class Wood** is a Manifest V3 extension for ultrawide monitor users who want edge-to-edge video.

_"Edge-to-edge video, no black bars."_

## Solution

- **One-click fill**
- **Ratios** 4:3, 16:9, 21:9 and 32:9
- **Zoom** from 50% to 300%
- **Horizontal and vertical reframing**
- **Works with** YouTube, Netflix, Prime Video, Disney+ and Max

## Tech Stack

- Chrome MV3 extension, React 19, Vite 6, Tailwind CSS 4
