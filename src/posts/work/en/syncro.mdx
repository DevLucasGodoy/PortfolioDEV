## Overview

**Syncro OS** is a web suite for distributors running the Oracle WinThor ERP. It does not replace the ERP: it mirrors the data to the cloud and adds modern modules on top. A First Class Dev product built in partnership with TG Distribuidora, where it runs in production. I led and built the platform, which has over 3,800 commits.

_"Your systems and your team in sync."_

## Problem

WinThor is robust but tied to the store's desktop. Field sales reps, managers away from the office and finance depend on legacy screens, manual reports and spreadsheets, with no consolidated view per branch.

## Solution

- **Sales Force** in the browser: dashboard, customer portfolio and orders with ERP price, stock and credit
- **SalesDash** with goals and indicators per branch
- **Purchasing and inter-branch distribution**, order management and release
- **Finance**, billing and P&L
- **HR** integrated with Control iD time clocks
- **TV Mode**, corporate chat and PWA

## Architecture

- **SyncroAgent**: a .NET 8 ETL running at the store, reading Oracle and SQL Server and syncing incrementally to Neon
- **Write-back**: an outbox writes to WinThor preserving operator identity and audit
- **Web**: reads only from Neon, never directly from Oracle
- **Python/FastAPI tools**: card settlement and reconciliation

## Tech Stack

- **Web**: Next.js 16, React 19, TypeScript, Tailwind CSS
- **Data**: Neon (PostgreSQL), Cloudflare R2, Oracle, SQL Server
- **Agent**: .NET 8, Dapper, Oracle.ManagedDataAccess, Npgsql
- **Security**: WinThor password login, JWT, MFA/TOTP, branch scope, per-module and per-screen access, audit log
- **Quality**: Playwright, xUnit and versioned migrations
