## Overview

Website for **TG Distribuidora**, an electronic security distributor with 4 branches in Mato Grosso do Sul, aimed at installers and resellers. It replaced the legacy PHP site.

## Solution

- **Catalog** filterable by category and brand, with product modal
- **Brand pages**
- **Branch map** with Leaflet
- **Local SEO** with JSON-LD and FAQ

## Tech Stack

- Next.js 16, React 19, TypeScript, Tailwind CSS 4, Motion, React Leaflet
