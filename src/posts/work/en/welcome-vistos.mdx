## Overview

Website for **Welcome Vistos**, a consultancy helping Brazilians with tourist, business and study visas for 8 countries. I've worked with the brand since 2023; this version replaced the original static site.

## Solution

- **Country and service sections**
- **Process and FAQ**
- **WhatsApp CTA** and contact form
- **Promo banner** with countdown
- **Conversion events** through Google Tag Manager

## Tech Stack

- React 18, Vite 7, TypeScript, Tailwind CSS, shadcn/ui, TanStack Query
