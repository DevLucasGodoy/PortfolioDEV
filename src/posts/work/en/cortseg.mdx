## Overview

Landing page for **Cortseg**, a razor-wire and perimeter protection manufacturer, aimed at distributors and resellers in Mato Grosso do Sul.

## Solution

- **Form** that opens a prefilled WhatsApp conversation
- **Product line**
- **Floating CTA**
- **Manufacturer** structured data in JSON-LD
- **Partner page**

## Tech Stack

- Next.js 15, React 19, TypeScript, Tailwind CSS
