## Overview

Website for **Nova Civil Engenharia**, with an identity inspired by technical blueprints, for people looking for structural, electrical, plumbing, pool and sauna projects.

## Solution

- **Filterable project gallery** with modal
- **Searchable FAQ**
- **Contact form** with client auto-reply
- **Google Analytics** to measure traffic

## Tech Stack

- Next.js 16, React 18, TypeScript, Tailwind CSS, shadcn/ui, Framer Motion
