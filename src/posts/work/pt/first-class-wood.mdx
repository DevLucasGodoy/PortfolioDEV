## Visão Geral

**First Class Wood** é uma extensão Manifest V3 para quem usa monitor ultrawide e quer vídeo de ponta a ponta.

_"Vídeo de ponta a ponta, sem barras pretas."_

## Solução

- **Preenchimento** com um clique
- **Proporções** 4:3, 16:9, 21:9 e 32:9
- **Zoom** de 50% a 300%
- **Reenquadramento** horizontal e vertical
- **Compatível** com YouTube, Netflix, Prime Video, Disney+ e Max

## Stack Técnica

- Extensão Chrome MV3, React 19, Vite 6, Tailwind CSS 4
