## Visão Geral

**FC Moments** é uma galeria colaborativa para eventos: cada convidado vira fotógrafo e nada se perde. Está em beta.

_"Memórias que duram para sempre."_

## Solução

- **Feed vertical** de fotos e vídeos
- **Upload direto** ao Cloudflare R2 com validação do arquivo
- **Convites** por QR Code ou link
- **Curtidas e comentários**
- **Senha e validade** na página pública
- **Painel** com múltiplos eventos

## Stack Técnica

- Next.js 16, React 19, Neon com Row Level Security, Cloudflare R2, Resend, Tailwind CSS 4, Zod
