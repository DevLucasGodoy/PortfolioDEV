## Visão Geral

**Servix** é um sistema para pequenos prestadores de serviço, como assistências técnicas, beleza e manutenção. Está em desenvolvimento.

_"Menos papel. Mais serviço."_

## Solução

- **Ordens de serviço**
- **Agenda** semanal
- **Cadastro de clientes**
- **Financeiro** e catálogo de serviços
- **Vitrine pública** para cada prestador

## Stack Técnica

- Next.js 15, React 19, Tailwind CSS 4
- PostgreSQL, Drizzle ORM, Auth.js, Zod
